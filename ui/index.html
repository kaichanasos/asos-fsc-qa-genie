          Settings

          Go to portal.azure.com, open Foundry and create your own API key.
          Your sign-in email

          To have your email typed in a task, edit the task, click + Variable where the email should go and pick LOGIN_EMAIL, for example: "On the sign-in page, enter LOGIN_EMAIL and click Next."

          The AI model only ever sees the name LOGIN_EMAIL, never your email.

          QA Genie

          Describe a web browser task in plain text, and an AI model carries it out in a real browser, returning a pass or fail verdict with a screenshot of every step.

          How to use

          1. Pick a task on the left or click + New, then write the steps and what you expect to see. Shared values go in Variables, secrets in Settings.
          2. Click Run and watch the browser work through each step. Several tasks can run at once.
          3. Read the verdict and check the screenshots. Past runs are under Run history.
