QA Genie
========

Write a test in plain English, and QA Genie runs it in Google Chrome for you,
with a screenshot of every step.

Getting started
1. Unzip this folder somewhere permanent, such as Documents. (Opening it inside the
   zip without extracting it will not work.)
2. Double-click "Start QA Genie.cmd". QA Genie opens in your browser.
   If Windows shows "Windows protected your PC", click "More info", then "Run anyway".
3. The first time, paste the API key you were given and click Save.

Keep the black QA Genie window open while you use it. Closing it stops QA Genie.

Google Chrome must be installed.

Your settings, tasks and results are kept in the "data" folder inside this folder.
To update QA Genie, unzip the new version, then copy your "data" folder into it
if you want to keep your settings, tasks and results. Without it, the new version
starts with its own tasks and asks for the API key again.
